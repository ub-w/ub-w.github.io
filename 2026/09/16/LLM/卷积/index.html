三、使用 Constant Memory 保存 Mask

1.为什么 mask 适合 constant memory

Mask 通常具有以下特点：

  • 数据量小；
  • kernel 执行期间保持不变；
  • 所有线程都会使用；
  • 同一 warp 的线程在同一轮循环中读取相同的 mask 元素。

当一个 warp 的线程读取相同 constant memory 地址时，constant cache 可以读取一次并广播给整个 warp。

Constant memory 总容量通常为64 KB。输入矩阵虽然也可能只读，但通常数据量太大，而且同一 warp 的线程会读取不同输入地址，因此不适合放入 constant memory。

3.适用条件

如果同一 warp 的线程读取许多不同 constant memory 地址，硬件需要按不同地址拆分处理，广播优势会消失。

六、为什么卷积适合 GPU

  • 不同输出元素彼此独立，可以映射到大量线程并行计算；
  • 每个输出元素执行多次乘加，比向量加法具有更多计算工作；
  • Mask 放入 constant memory 后，可以利用 warp 广播；
  • 相邻输出共享大量输入数据，shared-memory tiling 可以减少 global memory 流量。

性能比较时应区分：

Kernel 获得很高加速比，并不代表端到端程序具有相同加速比。若 CPU↔GPU 数据复制占主要时间，应让数据尽量留在 GPU 上完成后续运算。

七、总结

  • 卷积让一个线程计算一个输出元素，输出等于输入邻域与 mask 的加权和。
  • 输入坐标由 in = out + (maskIndex-R) 得到，越界位置可以按0处理。
  • Mask 小、只读且被所有线程共享，适合 constant memory。
  • 相邻输出的输入邻域重叠，因此 input tile 适合放进 shared memory 复用。
  • 本节中 T 始终表示 input tile 边长，output tile 边长为 T-M+1。
  • Tiling 不改变卷积计算量，而是减少 global memory 读取，提高计算访存比。
  • 优化同时引入 shared memory、同步和非活跃线程等代价，需要通过实际测量验证。
